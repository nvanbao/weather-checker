# weather-checker

Tra cứu thời tiết theo tên thành phố, viết bằng HTML, CSS và JavaScript thuần.
Dữ liệu lấy từ API miễn phí [Open-Meteo](https://open-meteo.com/) (không cần API key).

## Tính năng
- Tìm thành phố theo tên, tự đổi sang tọa độ
- Hiển thị nhiệt độ, cảm giác như, độ ẩm, tốc độ gió và dự báo 3 ngày tới
- Đổi đơn vị °C / °F (nhớ lựa chọn)
- Nhớ thành phố tìm gần nhất
- Dùng vị trí hiện tại của thiết bị
- Giao diện tối theo cài đặt hệ thống
- Biểu tượng emoji theo tình trạng thời tiết
- Giờ mặt trời mọc, lặn và giờ cập nhật dữ liệu
- Lưu 5 thành phố tìm gần đây, bấm để tìm lại
## Cách chạy
Mở file `index.html` bằng trình duyệt.
